## 背景

Lite 版虽然已经缩减服务和依赖，但设置窗口仍沿用上游 7 个分页与大量高级选项，和只保留
输入翻译、划词翻译、截图 OCR、有道及 DeepSeek 的产品边界不一致。

## 目标与范围

- 设置窗口只保留通用、服务、快捷键 3 个分页。
- 通用页只暴露查询语言、核心查询行为、OCR 复制和开机启动。
- 快捷键页只显示输入、划词、截图翻译和静默截图 OCR 4 个全局快捷键。
- 保留服务页作为有道、DeepSeek 启用状态和 DeepSeek API Key 的配置入口。
- 缩小设置窗口，并从 Lite target 排除不再展示的设置页源码。
- 完成 Debug 测试、Release 构建及本机 Lite App 替换安装。
