# 移除 Lite 划词翻译与静默截图 OCR

- 状态：completed
- 创建日期：2026-09-14
- 负责人：AnonymXXX
- 关联 Issue/PR：none

## 背景

Easydict Lite 的菜单和快捷键设置仍保留“划词翻译”与“静默截图 OCR”。用户明确要求删除这两个
功能，新的范围替代此前 Lite 保留划词翻译的决定。

## 目标与范围

- 目标结果：菜单和快捷键只保留输入翻译与普通截图翻译，不再提供划词翻译和静默截图 OCR。
- 允许修改路径：相关 Swift、Objective-C 源码及本任务 plan/history。
- 同任务 history：`docs/histories/2026-09/2026-09-14-remove-lite-extra-actions.md`
- 用户限制：保留普通截图翻译与 OCR；不推送远端，不制作 DMG。
- 非目标：不删除普通截图 OCR 共用的识别、查询和窗口基础设施。
- 验收标准：相关入口、快捷键注册和直接动作不可用；历史划词偏好不会在 Lite 启动后继续生效；
  Debug 稳定测试集、Release 构建、本机替换安装与签名校验通过。

## 工作计划

1. 核对菜单、快捷键、设置、配置与窗口动作之间的实际调用关系。
2. 删除两个功能的菜单、快捷键、设置和独立执行方法，并强制关闭历史划词偏好。
3. 运行静态检查、现有 Debug 测试与 Release 构建。
4. 替换安装并启动 Easydict Lite，校验签名与主程序哈希。
5. 完成 history、归档计划、创建本地提交并合入本地 `dev`。

## 风险与决策

- `snipTranslate` 与静默截图 OCR 共用部分 OCR 基础设施；只删除静默入口及专用动作，避免破坏普通
  截图翻译。
- 已安装版本可能持有开启划词监听的旧偏好；Lite 初始化时将该偏好重置为关闭。
- 不删除共享的选中文本基础设施，因为输入窗口和其他内部流程仍可能复用相关配置。
